## 系统边界

本文统一使用项目中的正式名称：

- **Vision Lab**：当前电脑上的非生产工作台，负责抽帧、预标、人工确认、冻结数据集、训练和离线验证。
- **Analysis Worker**：MacBook Pro 上的计算节点，负责抽帧、模型推理、OCR 和英雄识别。
- **BLREC Server**：NAS 上的业务协调与数据服务，不运行视觉模型。
- **模型包**：包含 ONNX、预处理规则、标签顺序、阈值、数据集版本、指标和文件校验值的不可变制品。单独一个 ONNX 文件不算完整模型包。

## 已确定的方案

1. 使用四个职责单一的小模型组成级联流程：对局流程、英雄选择、对局模式和结算检测。
2. 不让所有模型逐帧运行。只有画面状态模型低频扫描全片；其他模型只在开局、结算或模式有歧义的短窗口运行。
3. 模型提供“证据”，时间线状态机负责判断一局从哪里开始、在哪里结束。单帧分类结果不能直接创建一场对局。
4. 胜利／失败动画只作为上下文，不作为结算点，也不决定向前还是向后寻找结算页。
5. 接受／拒绝匹配属于 `match_confirm`，不是 BP；它只作为 BP 模型的 `not_bp` 难负样本。
6. 3V3 和大乱斗不能仅凭普通战斗画面强行二选一。BP、天赋选择和黄色光栅可以提供大乱斗证据；证据不足时输出 `unknown`。
7. “没有检测到光栅”不能证明是 3V3，因为镜头可能根本没有拍到入口。
8. 增加训练图片不会自动增加模型参数或让单次推理变慢。模型大小主要由网络结构和输入尺寸决定；数据增加主要影响训练时间。

## 2026-08-09 实现结果

- 已备份并迁移 32,734 条旧帧／缩略图路径；帧 ID、SHA-256 和人工标注未变，迁移后数据库 `PRAGMA quick_check` 为 `ok`。
- 已把旧数据冻结为首批累计快照：`screen-state-v1`、`bp-classifier-v1`、`key-screen-classifier-v1` 和 `result-detector-v3`。光栅数据修正按视频切分后冻结为 `mode-gate-detector-v3`。
- Analysis Worker 随正常分析复用五路旧模型输出，Server 按图片合并为四项统一预标并按 SHA-256 去重；NAS Server 只保存图片与 JSON，不运行模型。
- Vision Lab 的“新模型统一打标”页一次确认四项标签；仅真正结算正样本画一个完整面板框。它还会导入 BLREC 已识别对局保存的历史结算截图。
- 点击训练仍会先冻结新的 `*-vN` 累计快照；新增标注后再次训练会生成新版本，不覆盖旧快照或旧 run。
- 模型测试页直接读取 run 绑定的不可变快照，不依赖以后可能移动的原始帧。只有人工验收通过的 run 才能组包；任务不齐或固定测试集缺类时只能得到 `incomplete` 研究包。

## 实施顺序

### P0：恢复数据可读性并冻结基准集

2026-08-09 的目录整理把 Vision Lab 从 `scripts/vainglory_labeling` 移到了 `apps/vision-lab`，但 `lab.db` 中 32,734 条 `frame_path` 仍是旧绝对路径。图片实际存在于新目录，因此数据没有丢失，但 BP 和关键界面训练页会暂时显示为 0。

以下前置项已经完成：

1. 迁移数据库中的帧路径，并校验图片可读。
2. 重新运行历史训练任务的数据统计。
3. 冻结首批按视频切分的累计快照。真正的长期固定回归集仍需随着更多独立视频补齐，尤其是大乱斗 BP、`not_bp`、天赋、转场和开放入口。

### P1：先稳定结算链路

先迭代结算面板检测器。当前对局数据最终依赖真正结算页和 OCR，这条链路对业务结果影响最大，而且现有数据已达到试训量。

### P2：接入英雄选择开始锚点

补齐大乱斗英雄选择与 `not_select` 难负样本后训练英雄选择分类器。它负责给出开始锚点和初始模式证据，但必须等后续出现稳定的对局中画面，才能确认该选择确实进入了一局。

### P3：训练对局模式分类

用能看出地图的完整对局画面训练 3V3／大乱斗／5V5 分类器。旧黄色光栅和开放入口标注作为强证据迁移复用；新流程暂不要求继续画框。

### P4：替换旧的全片粗扫模型

根据现有统一标签训练对局流程二分类器，先以影子模式与 `multi-v2` 对比，再切换状态机。旧模型在完整录像回放验证通过前不删除。

## 完成标准

这套方案完成不是指“训练成功生成了 ONNX”，而是同时满足：

- 数据集有不可变版本，训练集、验证集和测试集按视频或录制场次隔离。
- 模型包明确记录输入预处理、标签顺序、阈值、指标和 SHA-256。
- 完整录像回放能正确配对最近的有效开始锚点与后续结算点。
- 证据冲突或不足时返回 `unknown`，不靠宽高比、未命中或单帧猜测模式。
- MacBook Pro 上记录实际耗时，级联方案相对当前基线没有不可接受的退化。
- 可以通过回退整个模型包或 Worker 版本恢复旧行为。
