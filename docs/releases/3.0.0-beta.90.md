# BLREC Server 3.0.0-beta.90

- 修复历史稿件的主播归属：优先读取简介中的原直播间，兼容多个链接、移动端链接和“直播间号”文本；标题和简介都无法确认时保持未归属，不再按识别昵称自动创建玩家。
- 新增稳定玩家别名，并让改名、直播间绑定和老稿件重新归属复用同一个玩家；上线后会低频重新核对已有历史稿件。
- 历史接入和历史搬运的每日上限提高到 1000，并记录稿件是否仅自己可见。
- 稿件回填新增分页记录、状态筛选、B 站稿件直达与完整重试；私密稿件改用所属账号登录态验证简介、评论和视频分段。
- 运行中心新增“实时直播”独立页签，并把容易混淆的“复核”统一改为“远端验证”。
