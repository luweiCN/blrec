# BLREC 3.0.0-beta.57

本版本修复历史稿件分析停止继续下载的问题。

## 历史稿件分析

- 夏季赛调整为下载与分析顺序上的优先级，不再作为历史同步的终止边界；夏季赛完成后会继续发现并处理更早的历史稿件。
- “每天 100 个”改为按当天首次实际提交下载的稿件数计数，只有发现元数据或下载失败不会消耗名额，同一稿件的多个分 P 也只计一次。
- 已经排队的分 P 会优先进入远程下载，并强制恢复曾被逻辑删除的本地缓存，避免在排队与分析状态之间空转。
- 放宽历史分页上限，仍会在空页、短页或重复页处自动停止。

本版本包含数据库迁移 68。迁移会清除旧口径下的每日计数，并重新开启尚未完成的历史发现任务。升级前必须先执行数据库备份并确认文件非空、`PRAGMA quick_check` 为 `ok`；现有配置、录制、日志和切片挂载均不变。
