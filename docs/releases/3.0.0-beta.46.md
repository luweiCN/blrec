# BLREC 3.0.0-beta.46

本版本补齐 `3.0.0-beta.45` 上线核对时发现的两个历史终态，确保已经建立的发布任务不会永久等待。

## 发布任务完整性

- 历史回填明确判定“稿件没有可分析的分 P”时，生成零对局发布版本并完成远端核对。
- 零对局版本会清理旧自动简介、旧评论和旧自动视频分段，不保留过时结果。
- 已发布稿件仍会立即建立任务；分析中的稿件继续等待真实结果，不会被误判为零对局。

## 失败任务恢复

- 升级时把仍有本地视频、未忽略且未排除的失败分析分 P 一次性重新排队。
- 被用户忽略的直播保持忽略，不会因升级自动恢复。
- 重新分析完成后保存不可变快照，并按结果变化执行全量核对重发。
