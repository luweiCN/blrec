# BLREC 3.0.0-beta.76

## 移动云 PostgreSQL 主库

- NAS 的稿件、分 P、录制会话、任务队列、对局、模型结果、Worker 状态、实时分析、
  训练候选元数据和访问日志归档可统一迁移到移动云 PostgreSQL 的 `core` schema。
- PostgreSQL 仍只监听移动云回环地址；NAS 通过固定网卡、固定源地址和严格主机密钥
  校验的 SSH 隧道访问，不向公网开放数据库端口。
- Dashboard Publisher 可直接以只读账号读取 `core`，公开网站继续只读取隔离的
  `public` schema。

## 安全迁移与备份

- 新增 SQLite 到空 PostgreSQL schema 的停写迁移工具；迁移前强制取得旧数据库
  独占锁、生成并校验 SQLite 备份，迁移后逐表核对行数。
- 数据库备份脚本会按当前后端选择 SQLite 在线备份或 PostgreSQL 自定义格式转储，
  并分别执行 `PRAGMA quick_check` 或 `pg_restore --list` 校验。
- PostgreSQL 不可用时不会自动回写 SQLite，避免恢复连接后形成两套冲突数据。

## 升级说明

本版本包含主数据库后端切换。首次迁移必须按
`docs/operations/postgresql-main-database.md` 停止写入、备份、迁移、验收；录像、截图、
训练图片、模型文件和日志原文件仍保留在 NAS，不写入 PostgreSQL。
