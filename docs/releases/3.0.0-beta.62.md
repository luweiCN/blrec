# BLREC 3.0.0-beta.62

## 管理与可观测性

- 管理后台新增“云成本”，集中查看阿里云账单、CDN 流量与 OSS 计费用量。
- 管理后台新增“访问分析”，支持按时间、页面、来源、设备、浏览器、地域和运营商筛选访客日志。
- 云成本与访客日志查询使用独立的固定网络用途，凭据只保存在服务端。

## 对局数据修复

- 修复缺失录播分页时无法完整恢复与重新分析的问题。
- 自动标记受模式、阵容冲突影响的直播场次，并加入重新分析队列。

## 运行稳定性

- 通知健康扫描改为批量持久化和独立后台任务，避免大量未变化状态阻塞其他任务。

## 升级说明

本版本新增阿里云只读查询环境变量，不新增数据库迁移或目录挂载。升级前仍须备份并校验数据库，保持现有配置、日志、录像、片段与分析数据挂载不变。
