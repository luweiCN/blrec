# BLREC 3.0.0-beta.55

本版本让公开排行榜在识别结果写入后近实时同步，并保留每日完整校验作为故障兜底。

## 排行榜同步

- 数据库新增持久化变更版本号；只有对局、玩家、英雄、直播与回放元数据变化时才会更新。
- 排行榜 Publisher 每秒只读取这一行版本号，检测到变化后等待 2 秒合并同批写入，再通过 API 增量同步；没有变化时不会扫描完整数据库或发起网络请求。
- 容器重启后会主动校验一次，失败批次继续通过持久化 outbox 使用相同幂等键重试。
- 历史对局补录仍按原始直播时间参与重算，不会追加到当前对局之后。

本版本包含数据库迁移 66。升级前必须先执行数据库备份并确认文件非空、`PRAGMA quick_check` 为 `ok`；现有配置、录制、日志和切片挂载均不变。
