# BLREC 3.0.0-beta.49

本版本兼容损坏或空白录制分 P，避免单个不可分析文件拖累整场直播的对局分析结果。

## 损坏分 P 兼容

- 零字节文件以及明确无法解析的视频会被保留为原始分 P，但从有效分 P 数量和视频总时长中排除。
- 一场直播同时包含正常与损坏分 P 时，正常分 P 的对局结果继续生效；只有全部分 P 都不可用时才标记整场失败。
- 服务启动时自动核对历史失败任务，将已知零字节或索引失败的小文件重新归类，无需重新分析已经成功的分 P。
- Analysis Worker 可用结构化失败类型报告 FFprobe 确认的视频损坏，普通网络、超时和算法错误仍按可重试失败处理。

## 管理端展示

- 对局分析任务显示有效、原始及已忽略分 P 数量。
- 直播详情显示损坏分 P 的忽略原因，视频总时长采用有效分 P 口径。
- 最近完成任务不再把被忽略的损坏文件显示为成功分析批次。
