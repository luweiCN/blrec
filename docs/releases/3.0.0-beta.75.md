# BLREC 3.0.0-beta.75

## Worker 写入性能

- Worker 完成分析时，结算截图、训练候选图片和元数据文件改在数据库写事务之外
  落盘。机械硬盘上的图片 `fsync` 不再占用 SQLite 单写队列，Worker 心跳、任务
  领取和实时预分析可以在素材保存期间继续写入。
- 保留结算截图的原子写入及训练候选的内容寻址去重；训练候选落盘失败仍不会把
  已完成的对局分析标记为失败。

## 升级说明

本版本不包含数据库迁移。NAS 更新前仍须执行数据库备份并确认备份非空、SQLite
`PRAGMA quick_check` 为 `ok`；保持 `/cfg`、`/log`、`/rec`、`/clips` 四个挂载不变。
