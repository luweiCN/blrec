# BLREC 3.0.0-beta.64

## 访问分析

- 服务端每 5 分钟把 SLS 中仍可读取的访问明细增量归档到 NAS 主数据库。首次启动会回补最近 7 天，随后长期积累；请求 UUID 用于去重，重启或重叠补扫不会生成重复记录。
- 本地只保存分析需要的事件、页面、来源、设备、浏览器、地域和运营商；匿名访客 ID 会再次单向哈希，不保存原始 IP 或完整 User-Agent。
- 访问分析的时间快捷选项补充为今天、昨天、最近 24 小时、最近 7/30 天、最近 3/6 个月、最近 1 年、本周/上周、本月/上月、本季度/上季度、今年/去年和全部。首次归档完成后可查询超过 SLS 7 天保留期的本地历史。

## 发布与升级

- 本版本新增数据库迁移 `0070`。NAS 更新前必须备份并校验数据库；升级后应确认 `visitor_analytics_sync_state` 没有同步错误，并在访问分析页看到本地归档起止时间。
- Analysis Worker 不需要升级，现有对局重分析任务会继续由 Worker `0.1.4` 处理。
