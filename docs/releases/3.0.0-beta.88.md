# BLREC Server 3.0.0-beta.88

- 历史搬运与历史接入现在共享同一条录像身份：搬运到目标账号的稿件不会再被目标账号历史扫描重复下载或分析，已有重复接入记录会在服务启动后自动隔离。
- 历史搬运继续沿用源稿件封面，并在源视频下载完成后进入现有对局分析队列；目标稿件审核通过后继续使用同一份分析结果完成简介、评论和视频分段回填。
- 历史搬运视频仅在目标稿件审核通过且对局分析完成后清理；普通录播继续沿用原有保留策略。
- 历史接入进度改为按 BV 号说明去重口径，并区分已扫描页数与尚未确认的总页数。
- 本版本不新增数据库迁移、环境变量或持久化目录，可从 `3.0.0-beta.75` 及更高版本直接升级。升级前仍必须使用 `scripts/backup_blrec_database.py` 生成并校验数据库备份。
