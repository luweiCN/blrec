# BLREC 3.0.0-beta.37

这是用于实际录像观察的 NAS 灰度测试版，重点降低虚荣结算画面精扫耗时，同时保留对短暂和窗口化结算页的识别能力。

## 场景自适应精扫

- 疑似结算区间仍以 4 fps 解码，以免漏掉停留不足一秒的结算页；昂贵的 ONNX 模型不再对每一帧运行。
- 精扫先用低成本画面网格比较场景变化；发生明显变化后连续检查 750 毫秒，并且每 3 秒固定执行一次兜底检查，静态或渐变出现的结算页仍有采样机会。
- 每个区间的日志会记录总采样帧、实际模型帧、场景变化次数和周期兜底次数，便于直接核对优化是否生效。

## NAS 推理优化与验证

- ONNX 结算页检测从单线程调整为两个推理线程，匹配当前 NAS 的四核 CPU；受控交替测试中单帧平均耗时由 0.683 秒降至 0.415 秒。
- 72 分钟慢样本中的短暂窗口化结算页仍在原时间点命中；NAS 上仍保留原视频的最近十局对局回放验证为 10/10 通过。
- 该慢样本的有效 70 秒搜索区间，模型调用由 385 次降至 52 次；整条分 P 预计由约 76 分钟降至 12～18 分钟，部署后继续用生产任务记录实测值。

## 升级说明

- 本版本不新增数据库迁移、环境变量或目录挂载。
- 虚荣分析算法版本 17 保持不变，升级不会自动重扫全部历史录像；尚未完成或手动重新分析的任务会使用新精扫逻辑。
- 升级前后保持 `/cfg`、`/log`、`/rec`、`/favorites`、`/clips` 与 `/result-frames` 的现有挂载不变。
