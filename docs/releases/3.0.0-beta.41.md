# BLREC 3.0.0-beta.41

这是补齐单局维护能力、修复历史稿件接入停滞，并继续压缩高噪声直播分析耗时的候选版本。

## 录制与分析

- 同一直播间在 3 分钟内短暂中断并恢复时，只要上一场尚未完成投稿收口，就继续使用原直播场次，避免网络抖动生成两场直播。
- HUD 连续性窗口不再只在 20 秒和 75 秒之间二选一。疑似区间仍过多时，会复用同一批粗扫结果，按 150 秒、300 秒逐级重新合并；超过 75 秒的合并必须具备相同阵容或高度相似的 HUD，避免单纯用大窗口牺牲准确率。
- 对局详情可只重新识别某一局原结算时间点，任务优先于普通 OCR 队列，不会重扫整场直播；识别失败时保留原结果并显示原因。
- 可直接删除误识别的某一局。对应分 P 和时间点会写入持久排除记录，后续整场重扫也不会重新加入同一误候选；人工再次标记该时间点时会解除排除。

## 历史数据接入

- 历史接入现在固定保存本轮赛季起止时间，只发现当前赛季稿件；翻页进入赛季开始时间以前后立即结束，不再遍历账号全部历史投稿。
- 修复稿件发现接口报错后，已有下载队列因为同步状态变为失败而全部停止领取的问题。升级时会清理赛季外、尚未物化的旧排队元数据，并恢复已经越过赛季边界的旧 `-400` 同步。
- 历史接入界面会明确显示本轮赛季范围；错误信息保留接口操作名及平台返回信息，便于区分参数边界、账号状态和平台风控。

## 发布与界面

- 继续使用独立的简介、评论和分段发布 worker；人工重发会进入最高优先级，列表会标出“手动重试优先队列”和最近状态更新时间。
- 简介与战绩评论的每局内容增加 3V3、5V5、大乱斗或模式待确认；视频分段继续携带比赛模式。
- 对局列表增加真实开播时间、分 P 数、录像总时长，并保留对局累计时长，便于直接核对识别局数。
- 移除“英雄库”管理入口；57 个内建英雄仍用于筛选、人工修正和识别，不影响相关功能。

## 升级说明

- 新增数据库迁移 0059，用于历史接入赛季范围、发布优先级、单局重新识别任务和误候选排除记录。
- 虚荣分析算法版本保持 18，不会因为升级自动重排已经由 beta.40 完成的全部分 P；需要验证具体旧稿件时可手动整场或单局重新识别。
- 不新增环境变量或目录挂载。
- 本版本仅发布到 GitHub 与 GHCR；等待人工确认后再部署 NAS。
