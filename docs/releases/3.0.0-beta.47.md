# BLREC 3.0.0-beta.47

本版本在 `3.0.0-beta.46` 的失败任务恢复基础上，移除旧上传分 P 映射对发布队列的永久阻塞。

## 发布任务完整性

- 整场分析已经完成时，旧上传稿件直接生成发布版本，不再要求历史 `upload_parts` 映射完整。
- 历史导入稿件仍严格等待自身全部分 P 分析完成，分析中的任务不会被提前发布。
- 没有可分析分 P 的稿件生成零对局版本，清理旧自动简介、评论和视频分段。

## 重新分析与恢复

- 可用且未忽略的失败分析分 P 在升级时重新排队。
- 重新分析结果保存不可变快照；结果变化后执行全量核对重发。
- 已发布稿件始终保留发布任务，重复生成不会造成任务遗漏。
