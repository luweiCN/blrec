# BLREC Server 3.0.0-beta.87

- 管理后台导航按“采集与内容、处理与发布、系统”重新分组；对局索引原有的 Worker、分析任务和历史接入入口合并为独立“运行中心”。
- 运行中心分别展示处理队列、内置与外置 Worker 节点、历史接入/搬运流水线和稿件完成证据，并提供日限额、暂停恢复与移动端布局。
- 稿件回填只有在简介、视频分段、评论内容及置顶位置都能从 B 站远端确认后才算完成；缺少置顶时只重试原评论的置顶，不会重复发送评论或图片。
- 新增数据库迁移 `0074_initial.sql`，把升级前已确认稿件放入低优先级远端复核；新稿件和实时分析仍优先处理。
- 升级前必须使用 `scripts/backup_blrec_database.py` 生成并验证 PostgreSQL 备份，再应用迁移和更新容器。
