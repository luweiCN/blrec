# BLREC 3.0.0-beta.35

这是用于实际录像观察的 NAS 灰度测试版，重点加入虚荣历史对局与玩家数据能力，并缩短长稿件的结算画面搜索范围。

## 虚荣对局与玩家资料

- 支持导入 B 站历史稿件，按分 P 下载、扫描并建立虚荣对局索引。
- 新增玩家资料库、玩家胜负榜与玩家数据榜，并把公开数据看板接入真实快照。
- 增强 3V3、5V5、闪电战与大乱斗识别；观战、回放、人机、练习和过短 3V3 对局不会计入正式排名。

## 长稿件扫描优化

- 粗扫不再为每个 HUD 调用计时器 OCR；30 秒近邻 HUD 优先视为同一局。
- 每个连续 HUD 段只稀疏识别英雄阵容，允许部分英雄暂时无法识别；长时间切换应用或重启后，阵容一致可重新关联到同一局。
- 粗扫阵容会随结算候选进入 OCR 阶段。HUD 与结算英雄明确不一致时拒绝候选，证据不足时保守保留。
- 双方击杀或经济不完整的局内装备面板不再作为结算截图；候选会在英雄补识别之前停止，避免继续消耗处理时间。
- 虚荣分析算法升级到算法版本 17，升级后已有对局会进入重新分析队列，以清理旧算法留下的错误结果。

## 验证与升级说明

- 针对 HUD 连续性、重启恢复、阵容冲突、候选传递和假结算面板新增回归测试，并通过 Black、isort、Flake8 与 mypy 检查。
- 对一段 52.54 分钟真实稿件的旧日志重放中，保守精扫窗口由 32.54 分钟缩短到 4.21 分钟；最终壁钟耗时仍以 NAS 部署后的重新扫描日志为准。
- 本版本不新增数据库迁移、环境变量或目录挂载，但算法版本变化会触发虚荣数据批量重算。升级前必须在运行中容器内执行数据库备份并确认 `PRAGMA quick_check` 为 `ok`。
