# BLREC 3.0.0-beta.44

这是修复虚荣对局发布积压，并启用 BLREC Server 独立镜像交付流程的 NAS 灰度测试版。

## 发布 worker 与积压修复

- 简介、战绩评论、置顶评论和视频分段已经收口到 Server 内的专用发布 worker；任务发现和实际投递由两个独立后台循环执行，不依赖投稿主循环。
- 生产数据中，worker 一直在正常投递，但大量已发布稿件尚未生成发布任务。根因是新算法要求先完成当前版本分析，而“已发布但缺发布任务”的直播此前没有独立优先级，会被普通历史分析积压淹没。
- 本版本把这类“发布债务”在视频扫描、OCR 和任务中心显示中统一提升到普通历史积压之前。已经存在、等待新分析结果刷新的发布任务也使用相同优先级。
- 不提高 B 站写入频率：实际远端操作继续逐账号串行，并保留原有动作间隔；修复只改变分析任务的领取顺序。

## 独立 Server 镜像

- BLREC Server 使用 `server-v*` 标签独立发布到 `ghcr.io/luweicn/blrec-server`，NAS 直接从 GHCR 拉取固定版本。
- Server 独立镜像只包含服务端和管理端，不包含 ONNX 模型、OpenCV、ONNX Runtime、RapidOCR 或 Analysis Worker 命令。
- Analysis Worker、Public Dashboard、Browser Extension 和 Vision Lab 分别保留自己的目录、依赖、测试与发布流程，不再和 NAS 镜像绑定发布。

## 升级说明

- 不新增数据库迁移、环境变量或持久化目录，可从 `3.0.0-beta.43` 直接升级。
- 升级前仍必须在运行中容器执行数据库备份，确认备份文件非空且 SQLite `PRAGMA quick_check` 为 `ok`。
- 必须保留现有配置、日志、录像、收藏、片段和结算截图挂载；部署后检查健康状态、版本接口、发布 worker 日志及发布积压是否持续下降。
