# BLREC 3.0.0-beta.63

## 对局分析修复

- 新时间线在视频结尾仍处于对局段时，会额外生成一个覆盖至文件结尾的结算验证窗口；只有结算检测真正命中后才会生成比赛，避免漏掉片尾完整结束的最后一局，也不会把中途断播直接算成比赛。
- 新增片尾漏扫批量恢复脚本。脚本会在入队前永久保存每个受影响分批的旧时间线、结算窗口、候选和比赛数据，重跑后逐项标记“找回比赛”“已验证但无结算”“仍然漏扫”或“尚未完成”。

## 发布与升级

- Analysis Worker 需同步升级到 `0.1.4`，才能实际使用新的片尾验证逻辑。
- 本版本不新增数据库迁移、环境变量或目录挂载。NAS 更新前仍须备份并校验数据库，保持现有配置、日志、录像、收藏、片段、结算截图和训练数据挂载不变。
