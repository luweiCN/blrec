# BLREC 3.0.0-beta.40

这是修正对局模式误判、补齐人工校正闭环，并统一发布重发逻辑的 NAS 灰度测试版。

## 识别与人工校正

- 粗扫会先定位并裁出窗口化录制或黑边中的真实游戏区域，再判断 HUD，修复 PC 模拟器与非标准画面比例下整场漏扫。
- HUD 默认仍按 20 秒连续性生成疑似区间；只有区间密度异常时，才复用同一批粗扫结果按 75 秒重新合并，降低低画质直播产生数百个精扫区间的耗时。
- 修复短暂结算页被误识别为 HUD，以及非对称投降结算页被操作区平衡规则拒绝的问题。
- 大乱斗天赋模式不再因任意一帧命中就成立，改为开局三次探测中至少两次命中，降低 3V3 圆形 UI 噪声造成的误判。
- 浏览器插件和“0 局待核对”都增加“标记对局”；时间点会并入候选并重扫对应分 P，本地原视频已清理时自动从远端稿件恢复。
- 对局详情支持人工修正模式、时长、胜负、队伍数据、玩家与英雄信息，也可只把某一局设为不计入玩家统计和排行榜。
- 人工修正按分 P 和结算时间持久化，后续重新分析时继续覆盖新识别结果，不会被重扫冲掉。

## 简介、评论与分段

- 简介、置顶评论和视频分段即使已经成功，也能单独重发。
- 每次重发评论前都会重新枚举稿件评论，删除本账号发布的全部历史顶层评论，再生成并发布当前结果；不会删除其他账号评论或评论回复。
- 视频分段继续在每局名称中携带 3V3、5V5 或大乱斗等比赛模式。

## 界面

- 首页顶部统计卡片和玩家列表卡片统一使用白色背景。
- “0 局待核对”可直接选择分 P 和时间，补录算法极难命中的短暂、半透明结算画面。
- 对局分析任务中心展示数据库保存的全部完成记录，并为运行中、等待中及已完成任务提供稿件或本地录像入口。
- SSE 中的统计或完成任务发生变化时，直播列表和“0 局待核对”列表会静默同步，不再依赖手动刷新。

## 升级说明

- 新增数据库迁移 0057 和 0058，用于持久化评论清理状态、人工对局标记、对局人工修正以及已完成分 P 的候选数量。

- 不新增环境变量或目录挂载；升级前后保持 `/cfg`、`/log`、`/rec`、`/favorites`、`/clips` 与 `/result-frames` 的现有挂载不变。
