# BLREC 3.0.0-beta.54

本版本修复历史稿件重新分析以及已完成迁移任务被错误暂停的问题。`3.0.0-beta.53` 因发布元数据校验未同步而没有生成公开镜像，本版本包含其全部改进并修正该校验。

## 稿件重新分析

- 点击“重新分析”时，如果本地视频已经删除、缺失或明确损坏，但已投稿稿件仍有有效的 BVID 和 CID，系统会自动下载对应分 P，再使用当前算法重新分析。
- 同一场直播中仍然可用的本地分 P 会直接复用，不会重复下载。
- 等待稿件下载的分 P 不会被分析 Worker 提前领取；下载完成后才会进入分析。
- 只有本地文件和可恢复稿件源都不存在时，才会提示没有可分析的视频文件。

## 历史任务状态

- 已经创建发布任务的历史迁移稿件不再受迁移批次暂停状态影响，简介、置顶评论和视频分段可以继续处理。
- 尚未创建发布任务的迁移项仍会保持暂停，避免越过人工暂停边界。
- 缺少本地视频、等待稿件下载的任务显示为等待队列，不再误显示为正在分析。

本版本不新增数据库迁移、环境变量或持久化目录，可从 `3.0.0-beta.52` 直接升级；部署前仍会执行数据库备份与完整性检查。
