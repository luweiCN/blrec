# BLREC Server 3.0.0-beta.98

本版本完善历史流水线调度，并为公开榜单增加站长私有视图。

- 历史接入和历史搬运的每日上限不再写死最大值，管理端可保存任意正整数；界面明确区分“今日入队”和真正完成的分析数。
- 手动重新识别同时获得远程视频下载与分析优先级，避免手动任务被普通历史下载长期阻塞。
- Analysis Worker 升级到 0.1.13，并与服务器共享同一 beta.98 核心版本。
- 玩家库支持“公开展示 / 仅站长可见”；公开榜单会排除隐藏玩家及其个人对局，站长视图保留完整数据。
- 仅自己可见稿件的回放入口不会再暴露给普通访客，站长视图可在通过身份验证后访问。
- 榜单 API 分别缓存公开数据和站长完整数据，站长密钥只通过请求头传递，私有响应禁止共享缓存。
- 新增 PostgreSQL 76 至 77 的显式事务迁移工具与生产备份约束，隐私状态及历史上限字段可安全升级。
