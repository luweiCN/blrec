# BLREC 3.0.0-beta.48

本版本修复视频分段时间反推和发布任务状态误导，并扩展视觉训练候选协议。

## 发布任务状态

- 管理端区分等待分析、等待投稿审核、审核失败、自动重试、人工暂停、旧版分段时间和识别数据异常，不再把所有未完成步骤统一显示为“已暂停”。
- 状态卡显示具体原因、建议操作和下次重试时间；需要重新识别与只需重算分段的情况分别标注。
- 投稿通过审核后才允许发布简介、评论和视频分段，避免审核期间提前调用章节接口。

## 视频分段修复

- 使用结算画面时间减去 OCR 对局时长反推开局时间，支持跨分 P 回溯。
- 录像从半局开始时使用最早可用视频时间，不再无限等待不存在的开局画面。
- 旧版时间算法造成的暂停任务在服务启动后自动重新排队；真正缺少 OCR 时长或分 P 映射的数据保留任务并明确要求重新分析。

## 对局分析任务

- “最近完成”同时展示当前分批的分批时长、对局累计，以及所在直播的
  视频总时长、对局累计，便于快速判断是否存在漏识别。

## 训练候选协议

- Analysis Worker 可回传画面状态、BP、关键界面、结算检测和模式门控候选，并携带归一化建议框。
- Server 将候选按图片合并成统一预标并保存到独立视觉数据目录，供 Vision Lab 人工复核；模型建议不会直接成为训练真值。
