# BLREC 3.0.0-beta.74

## 直播对局预分析

- 新增独立的直播预分析队列。录制期间每 30 秒获取一个不可变快照，由单独的
  Worker 线程完成粗分类；发现从对局内切换到对局外后，延迟获取完整结算区间并
  精扫，不占用现有录播分析并发。
- 直播中识别出的对局以“直播预识别”状态发布；分 P 结束后的正式全量扫描会删除
  或替换同一时间附近的预识别结果，避免重复统计。
- 保存置信度临界帧、状态变化帧、结算候选帧和定期代表帧，供统一打标平台继续
  扩充训练集。管理页展示直播数、实时任务、待精扫窗口、采样数和预识别对局数。

## 数据与访问性能

- SQLite 保持单写事务，同时使用四个只读 WAL 连接处理后台列表和状态查询，避免
  Worker 的领取、心跳和写入把管理页查询排在同一条单线程队列中。
- 公共排行榜 API 支持 PostgreSQL，并提供经过备份、完整性检查、空目标校验、逐表
  行数和内容版本核对的 SQLite 迁移工具。
- 排行榜页面改用 SSE 接收数据变化通知，取消固定的 30 秒和 60 秒轮询；连接恢复时
  自动重新同步当前数据。

## 升级说明

本版本包含数据库迁移 `0073_initial.sql`，用于直播预分析状态、精扫窗口、采样记录
以及预识别对局标记。NAS 更新前必须执行数据库备份并确认备份非空、SQLite
`PRAGMA quick_check` 为 `ok`；保持 `/cfg`、`/log`、`/rec`、`/clips` 四个挂载不变。
