# BLREC Server 3.0.0-beta.99

本版本收紧浏览器分局标记范围，并让历史视频下载队列透明、可控。

- 浏览器扩展的分局标记仅适用于“虚荣-卢伟”账号稿件；无关视频确认不适用后立即停止扩展轮询，服务端同步校验账号 UID。
- 运行中心新增真实远程视频队列，分别展示等待下载、正在下载、已下载待分析、正在分析与下载失败的分 P 数量。
- 历史接入界面明确区分“今日加入下载队列”和“今日已分析”，不再把每日额度误解为已经下载完成。
- 下载并发支持在线调整为每条线路 1–8 路，并持久化到数据库；调低并发不会中断正在下载的任务。
- Analysis Worker 升级到 0.1.14，并与服务器共享同一 beta.99 核心版本。
