# BLREC 3.0.0-beta.45

本版本修复对局分析发布 Worker 可能漏建任务、漏发简介/评论/视频分段，以及重新分析后无法追溯旧结果的问题。

## 发布任务完整性

- 已发布稿件立即建立发布任务，不再等待所有分析门槛满足后才建任务。
- 分析尚未完成的任务明确保留为等待状态；分析完成后自动生成发布版本。
- 旧算法结果、英雄未识别和零对局不再阻止任务创建。
- 升级时会把既有 `skipped`、失败、待刷新任务恢复并执行一次全量核对重发。

## 重新分析与历史版本

- 每次分 P 分析保存不可变快照，包括识别结果和结算图 SHA-256。
- 每次发布计划保存不可变版本、前一版本哈希、生成原因和最终确认时间。
- 内容指纹不再依赖数据库对局 ID，并包含简介、评论、视频分段和结算图内容。
- 结果未变化时只记录核对历史；结果或图片变化时删除旧评论并重新编辑简介、视频分段和评论。
- 新结果为零对局时会删除旧自动简介、旧评论和旧自动视频分段。

## 安全性

- 发布步骤不再以“空间不足”或“不支持分段”为成功跳过；任务会保留并继续重试。
- 结算图缺失不会在固定次数后永久停止，旧评论会清理后继续重发。
