# BLREC 3.0.0-beta.39

这是重新收紧结算候选区间、修复模式与假结算误判，并支持长期排除无对局直播的 NAS 灰度测试版。

## 扫描速度

- HUD 粗扫间隔由 10 秒缩短为 5 秒，结算边界定位更细；同一 NAS 十分钟样本的分析时间由约 604 秒降至约 206 秒，约为原来的 2.9 倍速度，整场效果仍以本轮全量重扫统计为准。
- HUD 消失后 20 秒内重新出现时，按局内临时打开积分板处理，不再为这类噪声展开完整精扫。
- HUD 持续消失时，只对 HUD 边界和后续明显画面变化的小区间执行 4 fps 模型核验；窗口不超过 12 秒时直接完成一次高帧率核验，避免多轮重复解码。

## 识别准确度

- 放宽大乱斗三张天赋卡在不同画面比例和窗口尺寸下的位置、间距与半径容差，减少大乱斗被识别为 3V3。
- 结算页左右操作区亮度特征必须保持基本平衡，拒绝死亡倒计时、局内积分板等只有单侧区域相似的假结算画面。
- HUD 阵容明确冲突时拆分为不同对局；短暂退出或积分板遮挡后阵容一致时仍可延续原对局。

## 0 局直播核对

- “0 局待核对”新增“确认无需扫描”；适用于确实没有对局或主播在播其他游戏的直播。
- 确认后，自动发现、手动重扫、批量重扫、OCR 领取和后续算法失效重排都会跳过该直播；“已确认不扫描”页签可随时恢复。

## 升级说明

- 新增数据库迁移 0056，用于持久化无需扫描的直播标记；不新增环境变量或目录挂载。
- 虚荣分析算法版本保持 17，不触发整个历史接入队列重排。部署时只把旧算法已经完成的有结果直播和 0 局待核对直播加入手动重新分析；本地视频已清理时先恢复对应稿件媒体。
- 升级前后保持 `/cfg`、`/log`、`/rec`、`/favorites`、`/clips` 与 `/result-frames` 的现有挂载不变。
