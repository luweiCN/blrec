# BLREC 3.0.0-beta.56

本版本为公开排行榜增加主播直播状态同步。

## 直播状态

- BLREC 开始和结束直播录制时都会推进排行榜数据源版本，Publisher 无需轮询 B 站即可同步状态。
- Publisher 将当前正在录制且已绑定玩家的直播间、直播标题和开播时间发送到 Dashboard API；没有新增对局时也能独立更新。
- 排行榜页面通过轻量接口刷新直播状态，不会重复下载整份排行榜数据，直播状态也不会影响玩家排名。

本版本包含数据库迁移 67。升级前必须先执行数据库备份并确认文件非空、`PRAGMA quick_check` 为 `ok`；现有配置、录制、日志和切片挂载均不变。
