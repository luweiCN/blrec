# BLREC Server 3.0.0-beta.97

本版本完善运行中心的队列可见性、实时任务优先级和稿件回填诊断。

- “处理队列”和“历史队列”摘要支持打开分页明细，历史接入与历史搬运可切换查看；移动端同步适配。
- 历史接入增加“今日下载 / 今日已分析”，历史搬运增加“今日搬运 / 今日已分析”，分析数只统计当天真正完成的稿件。
- 分析任务优先处理正在直播、手动任务和近期直播；稿件回填优先最新直播与人工重试，自动失败会降为后台优先级。
- 修复稿件回填页面周期性闪烁，以及对局索引“最近分析”排序不随新分析活动更新的问题。
- B 站视频分段失败会记录具体动作、错误码和经过安全过滤的原始提示，避免所有错误都显示为笼统的“接口拒绝”。
- 处理队列、历史队列和稿件回填列表均补充稳定渲染与分页回归测试。
