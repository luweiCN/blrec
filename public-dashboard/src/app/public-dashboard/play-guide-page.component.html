01 / CURRENT STATE

能玩，但要按社区服的方式来

中国大陆玩家应先连接东亚或东南亚加速线路，再启动游戏。

裸连通常会出现高延迟、丢包或地区判断不稳定。进入正确地区后，核心对战与组队码仍可使用；过去的账号资产、好友列表、正式段位和完整组队大厅没有恢复。

02 / NETWORK IN CHINA

先开加速器，再打开《虚荣》

从中国大陆连接海外匹配池时，加速器基本是正常游玩的前提。奇游和 UU 是国内常见选择；本站不接受推广，也不保证某个产品或节点长期可用，请以实际延迟和丢包为准。

  1. 01
    完全退出游戏

    先从后台划掉《虚荣》，不要在已经进入游戏后再切换地区。

  2. 02
    在加速器里搜索“虚荣”或“Vainglory”

    优先使用游戏专线；没有专线时，再按产品说明选择海外手游线路。

  3. 03
    明确选择东亚或东南亚

    东亚可尝试日本、韩国等节点，东南亚可尝试新加坡等节点；约人前必须确认大家在同一地区。

  4. 04
    加速成功后再启动游戏

    进入后先打练习或观察实战延迟；如果地区不对，退出游戏后重新选线。

常用产品入口： 奇游手游加速器 · 网易 UU。 不要同时开启多个加速器，也不要在对局中途切换节点。

04 / MATCHMAKING

按模式选择排队方式

公开匹配首选

3V3 排位

当前最容易开局。东亚要避开低活跃时段；东南亚通常全天都能找到玩家，但等待时间仍会波动。

人数不固定

大乱斗 / ARAL

仍有人游玩，但玩家池比 3V3 小。长时间没有结果时，先回到 3V3 或去对应地区社区询问。

先约满十人

5V5 内战

东亚和东南亚都很难靠单排凑满。通常在群里确定十人、分好两边，再统一改名和倒计时进队列。

一个人想马上玩

开加速器后优先排 3V3 排位；东亚没人的时段，可以在延迟可接受的前提下换东南亚。

和朋友组队，还需要补路人

使用低于 3000 的组队码，让朋友进入同一局或同一边，剩余位置继续由公开匹配玩家补齐。3V3 的公开池更适合这种玩法。

想打 5V5

把它当成一场需要组织的社区内战：先定地区、模式、人数和分边，最后才是同时点击匹配。

05 / PARTY CODE

组队码到底怎么用

组队码不是一个单独的输入框，而是写在每个人游戏昵称前面的数字。

这个数字会被当作过去的排位分参与匹配，同时决定选人界面和匹配范围。加上 -1 或 -2 后，还可以指定进入地图的哪一边。

先看 1600：决定选人界面

低于 1600 · 盲选

不会进入征召流程，直接使用盲选英雄界面。

高于 1600 · 征召 BP

进入带 Ban / Pick 流程的征召选人界面。

两条线各管一件事：1600 决定盲选还是征召 BP，3000 决定能否由路人补齐空位。

再看 3000：决定是否匹配路人

日常组队 · 需要路人补位 使用低于 3000 的数字 1200-1_各自昵称 · 盲选 2000-1_各自昵称 · 征召 BP

例如两位朋友想排 3V3 并在同一边，就使用同一个低于 3000 的数字；系统再匹配一名队友和三名对手。

满员内战 · 不要匹配路人 使用高于 3000 的数字 6666-1_各自昵称

只有已经凑齐 3V3 六人或 5V5 十人时才这样做。人数不满时，队列里几乎没有路人可以补位；高于 3000 也一定会进入征召 BP。

  1. 1
    先决定选人界面和是否需要路人

    盲选并补路人用低于 1600；征召 BP 并补路人用高于 1600、低于 3000；满员内战则用高于 3000。

  2. 2
    选一个最多四位的数字并约定分边

    盲选补路人可以用 1200，征召 BP 补路人可以用 2000，满员内战可以用 6666。同一时间尽量使用群里临时约定的码，降低与其他队伍撞码的概率。

  3. 3
    在游戏首页修改昵称

    点首页右上角的玩家名或 Guest，进入资料页后点铅笔图标，把名字改为下面的格式。

  4. 4
    确认地区、模式和队列完全一致

    所有人必须在同一服务器，选择同一个模式，并确认大家排的是同一种队列。

  5. 5
    群里倒计时，同时点击匹配

    如果有人没有进入或选人阶段退出，全员先取消，再重新核对名字和时间后一起排。

名字格式相同，数字范围决定匹配方式

只要求进入同一局 6666_小明

所有人使用同一个数字，系统决定双方分边。

固定左边 · 魔翼方 6666-1_小明

这一边的 3 人或 5 人都使用 -1。

固定右边 · 暗爪方 6666-2_小王

另一边的 3 人或 5 人都使用 -2。

A 队 · 5 人 名字统一写成 6666-1_各自昵称
B 队 · 5 人 名字统一写成 6666-2_各自昵称
它仍然不是私人房间

同码只会提高同局和分边的确定性，不能阻止其他人撞码进入。低于 3000 本来就会匹配路人；高于 3000 如果没有凑齐六人或十人，通常会一直等不到开局。内战结束后建议改回普通名字。

规则与格式参考： 中文社区组队码 / 狙击匹配说明。 如果你所在群使用了新的约定，以群内当日通知为准。

06 / TROUBLESHOOTING

排不到时，先判断是哪一类问题

延迟很高，或者频繁掉线

确认加速器仍在运行，节点与目标地区一致，并尝试同地区的另一条线路。不要在已经开局后切换节点。

东亚 3V3 一直没有人

先看北京时间：工作日白天和凌晨可能处于低活跃时段。可以晚些再排，或在延迟允许时切到东南亚。

为什么 5V5 一个人排不到？

目前两个亚洲地区的 5V5 都主要依靠社区内战。先去群里凑齐十人，再统一使用组队码，不建议持续盲排。

为什么这次是盲选，上次却进入了征召 BP？

检查昵称前面的数字：低于 1600 会进入盲选，高于 1600 会进入征召 BP。1600 只控制选人界面，是否匹配路人还要继续看 3000 这条线。

组队码正确，为什么仍然没有进同一局？

先检查数字范围是否符合目的：缺人补位必须低于 3000，满员内战才使用高于 3000。再逐项核对人数、地区、模式、队列类型、-1/-2 分边和点击匹配的时间。

换了节点，游戏还是进入原来的地区

完全退出游戏后再换线。部分设备可能需要清除应用数据或重装后重新判断地区；这样会删除本地昵称和设置，请先记下来。
